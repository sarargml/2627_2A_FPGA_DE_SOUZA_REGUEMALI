# FPGA Lab — DE SOUZA & REGUEMALI

This repository contains our work for the second-year FPGA labs at ENSEA during the 2026–2027 academic year. It brings together VHDL source code and lab reports documenting our designs, tests, and observations.

## Objectives

The labs introduce the complete FPGA development workflow:

- Design digital circuits in VHDL.
- Simulate and analyze their behavior.
- Compile designs and assign FPGA pins using Quartus Prime.
- Program the board and verify the results experimentally.

The exercises progress from controlling and blinking LEDs to designing an LED chaser, before moving on to a digital drawing system using rotary encoders and HDMI output.

## Hardware and Software

- **Board:** DE10-Nano with the Télécran mezzanine board
- **Target FPGA:** `5CSEBA6U23I7`
- **Development software:** Quartus Prime
- **Simulation software:** ModelSim
- **Hardware description language:** VHDL

## Lab Reports and Source Code

**The detailed reports are stored in the corresponding lab folders.** They include explanations, circuit diagrams, commented code, and experimental observations.

Additional lab reports and source files will be added as the work progresses.
